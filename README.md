# ClipRail

轻量、便携的剪贴板历史管理工具。后台自动记录复制的**文本**与**图片**，通过可快速显示 / 隐藏的**竖向侧栏**管理。数据完全保存在本地，不上传网络。

- 单文件原生程序，Windows / Linux 双平台
- Rust + egui，无需 Python、`.venv` 或 Qt
- SHA-256 自动去重，每日自动归档

界面效果可先用浏览器打开 `design-preview.html` 查看。

---

## 一、获取可执行文件（无需本地安装交叉编译环境）

1. 将解压后的**全部内容**上传到一个 GitHub 仓库（保持目录结构，包含隐藏的 `.github` 目录）。
2. 打开仓库的 **Actions → Build ClipRail**。
3. 点击 **Run workflow**。
4. 构建完成后，在运行详情页面底部下载：
   - `ClipRail-Windows` → `ClipRail.exe`
   - `ClipRail-Linux` → `ClipRail`

> 若 Actions 页面提示未启用，先点击“I understand my workflows, enable them”。

### 运行

- **Windows：** 双击 `ClipRail.exe`。
- **Linux：** `chmod +x ClipRail && ./ClipRail`。

首次运行会在可执行文件同级自动创建 `data/` 目录。

## 二、基本使用

| 操作 | 方式 |
| --- | --- |
| 显示 / 隐藏竖栏 | 默认 `Alt + V`（可在设置中修改） |
| 复制历史内容 | 单击 Item，左上方显示绿色 `✓ 已复制`，约 1 秒后消失 |
| 置顶 Item | 点击右上角“置顶”；置顶项浅蓝背景并固定在列表顶部 |
| 排序 | 按住 Item 上下拖动，松开即保存 |
| 删除单条 | 将 Item 拖出竖栏窗口后松开（边框变红提示） |
| 批量删除 | 勾选左上角复选框 → 顶部“删除 N” |
| 取消拖拽 | 拖动中按 `Esc`，不删除、不改变顺序 |
| 按日期查看 | 顶部下拉菜单：全部记录 / 今天 / 具体日期（均带数量） |
| 竖栏置顶 | 右上角合并状态按钮：自动隐藏 ↔ 已置顶 |
| 移动 / 调宽 | 拖动顶部空白区移动；拖动左侧边缘调宽（300–800 px） |

### Wayland 用户

若全局快捷键注册失败，可在系统“键盘快捷键”中绑定命令：

```bash
ClipRail --toggle
```

## 三、数据目录

所有数据保存在可执行文件同级的 `data/`：

```
ClipRail.exe
data/
├─ clips.json          # 记录索引
├─ settings.json       # 快捷键、边缘收纳、窗口位置与宽度
├─ images/             # 图片文件
└─ archives/           # 每日归档 2026-08-02.json
```

JSON 写入采用“临时文件 + 原子替换”；单条记录损坏、图片丢失、图片保存失败都不会阻塞启动或中断运行。

## 四、源码结构

```
src/
├─ main.rs          # 入口、窗口创建、--toggle
├─ app.rs           # 应用状态、主循环、自动隐藏与拖拽逻辑
├─ clipboard.rs     # 剪贴板线程（轮询 300 ms）
├─ hotkey.rs        # 全局快捷键解析与注册
├─ store.rs         # 本地存储、哈希、图片读写
├─ archive.rs       # 每日归档
├─ model.rs         # Item / Settings
├─ ui/
│  ├─ sidebar.rs    # 竖栏主界面
│  ├─ item.rs       # 单条 Item
│  ├─ settings.rs   # 设置窗口
│  └─ theme.rs      # 配色与字体
└─ platform/
   ├─ windows.rs
   └─ linux.rs
```

线程模型：主线程（GUI）/ 剪贴板线程（监听与写回）/ 快捷键事件。图片只保存一份，列表使用缩略图与懒加载（每帧最多解码 2 张，纹理缓存上限 60 张）。

### 本地构建（可选）

```bash
cargo build --release
```

发布配置已启用 LTO、`opt-level = "z"`、单 codegen unit、`panic = "abort"` 与符号移除。

## 五、界面设计要点

- 浅色、低干扰；画布 `#F9F8F7`，卡片白底 + `#E6E5E3` 边框，主色 `#2783DE`。
- Item 间距 11 px，圆角 10 px，悬停时边框轻微加深。
- 置顶 Item：浅蓝背景 + 蓝色边框 + 蓝色“已置顶”状态。
- 复选框恒在左上、置顶按钮恒在右上，窄宽下仍可见；“已复制”提示不遮挡二者。
- 图片按宽等比缩放，文本自动换行，无横向滚动、无重叠。
- 底部常驻一行操作提示：单击复制 · 上下拖动排序 · 拖出窗口删除 · ALT+V 显示/隐藏。
- 所有按钮文字均以矩形中心绘制，不受字体基线影响，上下严格居中。
- 中英文使用同一套字体（微软雅黑 / Noto Sans CJK）、字号取整数，避免半像素发虚。
- “已复制”的对勾与复选框对勾均为矢量绘制，不依赖 ✓ 字符，不会出现缺字方框。

## 六、程序图标与任务栏

- 图标为代码生成的 128×128 剪贴板图形（`src/icon.rs`）：蓝色底板 + 白色纸张 + 顶部夹子，带抗锯齿、缩小后仍清晰，不需要额外资源文件。
- Windows 下程序以普通窗口方式运行（`with_taskbar(true)`），**任务栏上会显示 ClipRail 图标**，可直接点击回到竖栏。
- 快捷键采用“窗口内优先 + 全局辅助”双通道：鼠标在竖栏范围内、窗口已获得焦点时，按键优先由程序自身处理，不会被输入框等控件吸走。
